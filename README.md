# 游戏服务端工程师面试攻略

> 面向 **5 年+ / 资深架构级** 游戏服务端工程师的社招面试通关指南。C++ 为主，Lua/Go 为辅，覆盖通用服务端各类游戏场景。

📖 **[开始阅读（在线电子书）→](https://luckinbyte.github.io/game-server-book/)**

这本书不是八股合集。它围绕游戏服务端工程师的**四条岗位方向**（框架开发、架构/技术专家、核心业务系统、同步/玩法底层专家）与**五大能力聚类**组织，每章先建立**原理体系**，再配**分层面试题**——每道题都给出参考思路、考点解析、常见误区和追问方向，既能系统补强，也能临场应试。

> 全书 22 章 · 约 23 万字 · 200+ 道分层面试题，已过统一审校修订。

## 谁适合读
- 准备游戏服务端社招（3-5 年至资深架构）的工程师
- 想从"会用"进阶到"懂底层、能架构、会权衡"的服务端开发者
- 招聘方想校准面试深度的技术负责人

## 如何使用
1. **按篇循序**：第一篇打底（语言/底层/CS），第二篇服务端核心，第三篇游戏专项，第四篇架构进阶，第五篇实战。
2. **每章两段式**：上半「原理体系」建立知识框架，下半「面试题」检验与深化。
3. **题目结构**统一为：`参考思路 → 考点解析 → 常见误区 → 追问方向`。难度标注为【基础】【进阶】【专家】。
4. **资深建议**：跳过基础题，重点攻【专家】题与第五篇的系统设计/故障复盘。

## 内容来源
全书按游戏服务端岗位的核心能力，聚类为五大篇：语言与底层基础、服务端核心技术、游戏专项、架构进阶、面试实战，由浅入深、由点及面。
